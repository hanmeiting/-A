# 金元宝模型

> 支撑最强（头）。须先满足 [通用条件.md](./通用条件.md)。不构成投资建议。  
> 总览见 [总结.md](./总结.md)

## 规则

1. **支撑位** = `涨停收`（锚定涨停日收盘价）  
2. 涨停日之后至今日，每日 **收盘** 不低于支撑位（允许下影；收盘微破 ≤ **0.02 元**）  
3. 判定看 **收盘**，不要求最低价不破支撑  

## 在三级中的位置

支撑由强到弱：**金元宝 → 银元宝 → 汉堡包**。  
命中金元宝后，不再归入银元宝 / 汉堡包。
