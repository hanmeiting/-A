# 分时三龙（规则近似）

> 独立于 [金银汉堡包](./金银汉堡包.md)。不构成投资建议。  
> 总览见 [总结.md](./总结.md)  
> 近5日命中票的样本归纳见 [分时三龙_样本规律.md](./分时三龙_样本规律.md)  
> **2026-10-20 修订**：盘后命中以「振幅 + 时序」为硬条件；贴黄改为**分档计入**（★/○/△/弱），不再「均偏>0.8% 一律不进池」。隔段允许更宽贴黄上限；贴板仍更严。  
> **盘中**与盘后对齐：筛选对象就是「涨停前那一段趴着整理」，参数按 10/20 五只计入样本的抬头前横盘归纳（见第 5 节）。

源自量波「股海三龙」：以分时**均价线（黄线 / 人线）**为轴，盘中先**窄幅横盘**，再**抬头向上**（盘后确认再要求最终**涨停**）。  
程序可用横盘段均价近似「人线」；**盘中优选以软件分时黄线为准**。属规则近似，仅研究参考。

**核心偏好**：**白线贴着黄线走，越近越好**；排序看贴黄紧密度。上下甩、离黄线远的，在**硬条件仍满足**时可降档计入，不直接否决隔段合格票。

**选池原则（2026-10-16）**：**不要求当日主线，不要求近期曾涨停**；只要分时形态符合即可。

**盘中默认扫法（强制）**：**全市场沪深主板扫描** → 再套硬门槛（非 ST、非科创/创业/北交、**市值 < 1000 亿**、**涨幅 < 4%**、**距板 > 3%**）→ 再看贴黄/窄横。  
**禁止**先按「今日主线 / 热门板块 / 手工主题名单」缩池后再筛（会漏亚普、天顺、龙建这类非主线合格票）。池子太大时：仍须先全市场过硬门槛，再按贴黄紧密度截断至约 10～20 只。

---

## 1. 共性前提（盘后确认涨停时）

1. **仅沪深主板**涨停；非 ST；**禁止科创板（688）/ 创业板（300/301）/ 北交**  
2. **总市值 < 1000 亿**（按确认当日口径；≥1000 亿不计入命中）  
3. **非早封 / 秒板**：约 09:52 前封死不计（集合竞价一字、开盘秒板无三龙横盘过程）  
4. 先找到一段合格**横盘窗口**，再要求其后**抬头**并封板  
5. 抬头幅度 = `(涨停价 − 横盘均价) / 横盘均价`  
6. **不要求**题材是否主线、此前是否有过涨停——只看分时是否走出三龙

## 2. 卧龙 / 蛟龙 / 潜龙（相对均价）

在**横盘窗口内**，看分时价相对该段均价（近似黄线）的位置：

| 类型 | 经典形态（量波） | 程序判定（横盘段内） |
|------|------------------|----------------------|
| **卧龙** | 白线（分时价）多数时间**躺在黄线上方** | 价 ≥ 均价 的分钟占比 **≥ 75%** |
| **蛟龙** | 白线**缠绕**黄线上下 | 占比在 **35%～75%** 之间 |
| **潜龙** | 白线多数时间**躲在黄线下方** | 价 ≥ 均价 的分钟占比 **≤ 35%** |

共性动作（三种龙相同）：横盘蓄势 → 均价线上方抬头拉升 →（盘后确认）封涨停。  
兼具卧龙与潜龙特征、或上下缠绕不清楚时，归为**蛟龙**。

> 龙型只说明白线在黄线哪一侧；**选池优先级看「贴黄线紧不紧」**，不看卧/蛟/潜谁更高贵。

## 3. 两种时序模式（贴板 / 隔段）——硬条件

| 模式 | 含义 | 横盘参数 | 抬头 | 其它 |
|------|------|----------|------|------|
| **贴板** | 封板前**末端**仍在窄横，随后直接抬头封板 | 窗口 25～90 分钟；振幅 **≤ 2.5%** | **≥ 1.8%** | 横盘紧贴封板前 |
| **隔段**（农心型） | **先**窄横盘，**隔开一段时间**再冲板 | 窗口 **≥ 45** 分钟；振幅 **≤ 1.2%** | **≥ 5%** | 横盘结束后至封板**不破**横盘均价的 98%；可与封板间隔较久 |

例：农心科技 10/12，约 10:46–11:30 窄横（价绕均价）→ 午后冲板，**隔段 + 蛟龙**。

> **硬条件 = 第 1 节前提 + 本节振幅/窗口/抬头（及隔段不破均价）**。过硬条件后，再用第 3.1 节贴黄**分档**，决定优质 / 次优 / 弱贴黄，而不是一刀切剔除。

## 3.1 贴黄分档（盘后统计用 · 2026-10-20）

横盘段内：`均偏黄` = 各分钟 `|价−黄线|/黄线` 的均值；`最大偏黄` = 段内最大偏离。

| 档 | 均偏黄 | 最大偏黄（参考） | 是否计入「三龙涨停」 | 说明 |
|----|--------|------------------|----------------------|------|
| **★ 优质** | **≤ 0.25%** | **≤ 0.7%** | **计入** | 白线趴黄，优先样本 |
| **○ 优质** | **≤ 0.45%** | ≤ 1.2% | **计入** | 可贴，略松于 ★ |
| **△ 次优** | **≤ 0.8%** | ≤ 1.5% | **计入** | 贴黄一般，但窄横+抬头成立；样本：日出东方、南威软件 |
| **弱（仅隔段）** | **≤ 1.5%** | **≤ 1.8%** | **计入** | 须同时满足：**隔段**硬条件（振幅≤1.2%、抬头≥5%）；样本：晶华新材、安记食品 |
| **不计** | 超出上表 | — | **不计入** | **贴板**均偏 **> 0.8%**（或最大偏 > 1.8%）→ 末端乱抖，形态差（如春光科技、长龄液压）；隔段均偏 **> 1.5%** 或最大偏 **> 1.8%** → 也不计 |

排序（研究/观察优先级）：**★ → ○ → △ → 弱**；同档再比缩量、封板质量。

**为何隔段比贴板宽**：隔段横盘离封板更远，分钟均价与黄线天然更容易偏一点；只要**振幅够窄、抬头够大、不破横盘均价**，仍属「先磨后冲」三龙结构。贴板要求末端贴黄更紧，避免把「末端上下乱晃后偶然封板」算进来。

## 4. 盘后确认（已涨停）

```
主板涨停池 → 剔科创/创业/北交/ST → 剔市值≥1000亿 → 剔早封
    → 找横盘窗口（贴板末端 / 隔段先横后冲）且振幅·抬头硬条件达标
         → 按价相对均价占比标 卧龙 / 蛟龙 / 潜龙
              → 按 3.1 贴黄分档：★/○/△/弱(隔段) → 计入命中
                   → 贴板且均偏>0.8%，或隔段超出「弱」上限 → 不计入
（不校验主线 / 不校验此前是否涨停）
```

盘后报表建议分列：**优质（★/○）**、**次优（△）**、**弱贴黄·隔段（弱）**；三者合计 = 当日三龙涨停家数。

## 5. 盘中筛选：盯「涨停前那一段趴着」（散户口径）

目标：盘中找的，就是日后复盘里**封板前那段窄横趴黄**——还在磨、还没封（或刚要抬头）。  
不是另 invent 一套盘中形态；**盘中 A 档 ≈ 盘后命中票在抬头前的那截分时**。

散户原则：**硬门槛缩池 → 只认「趴着整理段」→ 贴黄分档 → 缩量 → 抬头放量再盯**。

### 5.0 趴着整理段（盘中核心对象）

| 要素 | 标准（对齐盘后硬条件） | 10/20 计入样本（抬头前） |
|------|------------------------|--------------------------|
| **在干什么** | 白线沿黄线（或略缠）**缩量横磨**，未散开、未单边冲板 | 五只均为先趴后冲 |
| **窗口长度** | 已持续约 **≥ 25 分钟**（隔段苗力争 **≥ 45 分钟**） | 信通 47m；南威/日出/安记/晶华约 45～70m+ |
| **近窗振幅** | **≤ 1.2%** 优先（典型隔段趴）；贴板末端苗允许 **≤ 2.5%** 但贴黄要更紧 | 五只隔段振幅均约 **0.95%～1.18%** |
| **相对黄线** | 按 3.1 / 5.2 分档：★/○/△ 都算趴住；隔段可到**弱** | ★信通；△南威、日出；弱安记、晶华 |
| **现价位置** | 仍在整理区间内：相对本段均价约 **-2%～+3.5%**；未放量脱离黄线狂奔 | 抬头前都还在磨 |
| **距涨停** | **> 3%**（已近板/已封的不算「还在趴」） | 趴的时候都还没封 |
| **量能** | 本段量 **明显小于** 开盘前半小时或上一波拉升（缩量横） | 肉眼偏缩即可 |

两种趴法（对应盘后两种模式）：

| 盘中苗 | 长什么样 | 之后常见演化 | 贴黄要求 |
|--------|----------|--------------|----------|
| **隔段趴**（主） | 早盘或午前已磨 **≥45 分钟**、振幅 ≤1.2%，现价离板仍远 | 隔一段时间再拔（可午后） | ★/○/△/弱 均可进 A 档 |
| **贴板趴**（次） | 封板前末端才收窄 **25～90 分钟**，振幅 ≤2.5%，离板渐近但仍 >3% | 一抬头就封 | 仅 ★/○/△（均偏 **≤0.8%**）；更严 |

> 口诀：**先找「还在趴着的窄横」，再等人家抬头。** 不要找已经竖着拉的票。

### 5.1 先缩池（必做 · 全市场 + 硬门槛）

**第一步必须是全市场沪深主板扫描**（程序拉全市场列表，或等价全量接口），**不得**用主线/题材/自选/近期涨停名单代替候选池。

硬门槛（在全市场结果上过滤）：

1. **仅沪深主板**；非 ST；**不要科创板 / 创业板 / 北交**  
2. **总市值 < 1000 亿**（≥1000 亿直接剔除）  
3. **今日涨幅 < 4%**（≥4% 不进盘中观察池；已拉太高，赔率差）  
4. **不要快封板**：距涨停价空间 **≤ 3%**（或现价 ≥ 涨停价 × 0.97）直接剔除；一字 / 早封 / 已近板同样剔除  
5. **不要求**当日主线、板块联动、近几日曾涨停或自选——**分时趴着合格即可入池**  
6. 过硬门槛后若仍过多：按 **贴黄线紧密度 → 缩量质量** 排序，保留约 **10～20 只**展示（截断发生在全量扫描之后，不是截断之前）

### 5.2 「贴黄线」（盘中 · 量趴着紧不紧）

对**当前这段趴着整理窗**量贴黄（与 3.1 盘后分档同一套数）：

| 指标 | ★ | ○ | △ 可观察 | 弱（仅隔段趴） | 不进池 |
|------|---|---|----------|----------------|--------|
| **均偏黄** | **≤ 0.25%** | ≤ 0.45% | ≤ 0.8% | ≤ 1.5% 且近窗振幅 ≤ 1.2% | 贴板趴 > 0.8%；隔段趴 > 1.5% |
| **最大偏黄** | **≤ 0.7%** | ≤ 1.2% | ≤ 1.5% | ≤ 1.8% | 超出对应档 |
| **现偏黄** | 约 **−1%～+1%** | −1.5%～+1.5% | −2%～+2% | 同左 | 已放量甩离黄线、不像在趴 |
| **近窗振幅** | **≤ 1.2%** 更佳 | 贴板趴 ≤ 2.5%；隔段趴 ≤ 1.2% | 同左 | **必须 ≤ 1.2%** | 振幅过大 = 没趴住 |

排序：**★>○>△>弱**，再比缩量。  
10/20 启示：隔段趴可以均偏到 ~1.3% 仍算合格弱档；**不要**用「非 ★/○ 就丢」漏掉南威/日出/安记/晶华这类。

辅助：

- **日振幅过大**（早盘已拉一波）：若近段已重新收窄趴黄，可进 ○/△，标注「早拉后趴」；近段仍不贴黄 → 不进。  
- 肉眼：叠在黄线上磨 = 优；绕黄小波浪 = 隔段可弱档；末端大幅上下抽 = 没趴住，出局。

### 5.3 「正在趴着 / 刚抬头」判定

| 条件 | 标准 |
|------|------|
| 市值 / 涨幅 / 距板 | 同 5.1（<1000 亿、<4%、距板 >3%） |
| **趴着窗口** | 最近已持续 **≥25 分钟**；隔段趴 **≥45 分钟** 更像 10/20 样本 |
| **趴着振幅** | 隔段趴 **≤1.2%**；贴板趴 **≤2.5%** 且贴黄 ≤△ |
| **贴黄分档** | ★/○/△ 进池；**弱仅隔段趴**；贴板趴均偏 >0.8% 不进 |
| **缩量横** | 本段量明显小于开盘前半小时或上一波拉升 |
| **仍在区间** | 现价相对本段均价约 **-2%～+3.5%** |
| 龙型 | 卧 / 蛟 / 潜（认大概即可） |
| **抬头放量（升级）** | 破整理上沿或抬离黄线 + 放量 → 标「抬头中」→ B 档 |
| 主线 / 曾涨停 | **不作为条件** |

两档：

- **A 档·趴着观察**：已识别合格趴着段（含 △/弱隔段）+ 缩量 → 挂着，**不追已经竖拉的**  
- **B 档·抬头盯盘**：A 档票破上沿/放量抬头 → 才加密（假突破：放量甩黄又砸回 → 降回 A 或踢出）

### 5.4 多久找一次（建议节奏）

趴着要二三十分钟才成型，**不必每分钟刷**。

| 时段 | 动作 | 间隔 |
|------|------|------|
| **09:30–10:00** | 噪声大；可只扫有无「已磨 ≥25m」的早盘趴 | 可跳过或 1 次 |
| **10:00–11:30** | **主筛隔段趴**：找振幅 ≤1.2%、已 ≥45m 的趴黄票进 A 档 | 约 **20～30 分钟** 一轮 |
| **13:00–14:30** | 隔段二次抬头高发；刷上午留下的 A 档 + 新趴 | 约 **15～20 分钟** 一轮 |
| **14:30 后** | 假突破多 | 只盯已有 B 档，**不再广筛新趴** |
| **B 档出现后** | 单票跟分时 | **5～10 分钟** 或设「破横盘高点」提醒 |

一句话：**广筛半小时找「还在趴的」；一抬头再加密。**

### 5.5 盘中用法

```
全市场沪深主板扫描（禁止先按主线/题材手工缩名单）
    → 硬门槛：非ST、非科创/创业/北交、市值<1000亿、涨幅<4%、距板>3%
         → 找「趴着整理段」（≥25m；隔段苗≥45m + 振幅≤1.2%）
              → 贴黄分档（★/○/△；弱仅隔段趴）+ 缩量 → A 档
                   → 按贴黄紧密度截断约 10～20 只
                        → 破上沿 + 放量 → B 档盯盘
                             → 若最终封板，用第 3 / 3.1 / 4 节做盘后分档确认
```

池内排序：**贴黄紧密度 ↓ → 缩量质量**。  
说明：A 档是**涨停前趴着的观察池**，多数不会封板；与盘后命中是同一套形态的不同时点。
