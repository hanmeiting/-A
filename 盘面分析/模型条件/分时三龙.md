# 分时三龙（规则近似）

> 独立于 [金银汉堡包](./金银汉堡包.md)。不构成投资建议。  
> 总览见 [总结.md](./总结.md)  
> 近5日命中票的样本归纳见 [分时三龙_样本规律.md](./分时三龙_样本规律.md)

源自量波「股海三龙」：以分时**均价线（黄线 / 人线）**为轴，盘中先**窄幅横盘**，再**抬头向上**（盘后确认再要求最终**涨停**）。  
程序可用横盘段均价近似「人线」；**盘中优选以软件分时黄线为准**。属规则近似，仅研究参考。

**核心偏好**：**白线贴着黄线走，越近越好**；上下来回甩、离黄线远的（即使振幅表上看似合格）降权或不进观察池。

**选池原则（2026-10-16 修订）**：**不要求当日主线，不要求近期曾涨停**；只要分时形态符合即可。

**盘中默认扫法（强制）**：**全市场沪深主板扫描** → 再套硬门槛（非 ST、非科创/创业/北交、**市值 < 1000 亿**、**涨幅 < 4%**、**距板 > 3%**）→ 再看贴黄/窄横。  
**禁止**先按「今日主线 / 热门板块 / 手工主题名单」缩池后再筛（会漏亚普、天顺、龙建这类非主线合格票）。池子太大时：仍须先全市场过硬门槛，再按贴黄紧密度截断至约 10～20 只。

---

## 1. 共性前提（盘后确认涨停时）

1. **仅沪深主板**涨停；非 ST；**禁止科创板（688）/ 创业板（300/301）/ 北交**  
2. **总市值 < 1000 亿**（按确认当日口径；≥1000 亿不计入命中）  
3. **非早封 / 秒板**：约 09:52 前封死不计（集合竞价一字、开盘秒板无三龙横盘过程）  
4. 先找到一段合格**横盘窗口**，再要求其后**抬头**并封板  
5. 抬头幅度 = `(涨停价 − 横盘均价) / 横盘均价`  
6. **不要求**题材是否主线、此前是否有过涨停——只看分时是否走出三龙

## 2. 卧龙 / 蛟龙 / 潜龙（相对均价）

在**横盘窗口内**，看分时价相对该段均价（近似黄线）的位置：

| 类型 | 经典形态（量波） | 程序判定（横盘段内） |
|------|------------------|----------------------|
| **卧龙** | 白线（分时价）多数时间**躺在黄线上方** | 价 ≥ 均价 的分钟占比 **≥ 75%** |
| **蛟龙** | 白线**缠绕**黄线上下 | 占比在 **35%～75%** 之间 |
| **潜龙** | 白线多数时间**躲在黄线下方** | 价 ≥ 均价 的分钟占比 **≤ 35%** |

共性动作（三种龙相同）：横盘蓄势 → 均价线上方抬头拉升 →（盘后确认）封涨停。  
兼具卧龙与潜龙特征、或上下缠绕不清楚时，归为**蛟龙**。

> 龙型只说明白线在黄线哪一侧；**选池优先级看「贴黄线紧不紧」**，不看卧/蛟/潜谁更高贵。

## 3. 两种时序模式（贴板 / 隔段）

| 模式 | 含义 | 横盘参数 | 抬头 | 其它 |
|------|------|----------|------|------|
| **贴板** | 封板前**末端**仍在窄横，随后直接抬头封板 | 窗口 25～90 分钟；振幅 **≤ 2.5%** | **≥ 1.8%** | 横盘紧贴封板前 |
| **隔段**（农心型） | **先**窄横盘，**隔开一段时间**再冲板 | 窗口 **≥ 45** 分钟；振幅 **≤ 1.2%** | **≥ 5%** | 横盘结束后至封板**不破**横盘均价的 98%；可与封板间隔较久 |

例：农心科技 10/12，约 10:46–11:30 窄横（价绕均价）→ 午后冲板，**隔段 + 蛟龙**。

## 4. 盘后确认（已涨停）

```
主板涨停池 → 剔科创/创业/北交/ST → 剔市值≥1000亿 → 剔早封
    → 找横盘窗口（贴板末端 / 隔段先横后冲）
         → 按价相对均价占比标 卧龙 / 蛟龙 / 潜龙
              → 抬头达标且最终封板 → 命中
（不校验主线 / 不校验此前是否涨停）
```

## 5. 盘中筛选：正在形成（散户口径）

目标：盘中圈**还在横盘 / 刚要抬头**的观察池，不是等收盘复盘。  
散户原则：**硬门槛缩池 → 只看分时（贴黄 + 缩量横）→ 抬头放量再盯**；规则宁简勿繁。

### 5.1 先缩池（必做 · 全市场 + 硬门槛）

**第一步必须是全市场沪深主板扫描**（程序拉全市场列表，或等价全量接口），**不得**用主线/题材/自选/近期涨停名单代替候选池。

硬门槛（在全市场结果上过滤）：

1. **仅沪深主板**；非 ST；**不要科创板 / 创业板 / 北交**  
2. **总市值 < 1000 亿**（≥1000 亿直接剔除）  
3. **今日涨幅 < 4%**（≥4% 不进盘中观察池；已拉太高，赔率差）  
4. **不要快封板**：距涨停价空间 **≤ 3%**（或现价 ≥ 涨停价 × 0.97）直接剔除；一字 / 早封 / 已近板同样剔除  
5. **不要求**当日主线、板块联动、近几日曾涨停或自选——**分时形态合格即可入池**  
6. 过硬门槛后若仍过多：按 **贴黄线紧密度 → 缩量质量** 排序，保留约 **10～20 只**展示（截断发生在全量扫描之后，不是截断之前）

### 5.2 「贴黄线」（盘中核心，优先于单纯振幅）

横盘段内用**分时黄线（均价线）**衡量白线贴合度（程序可用分钟收盘相对该分钟均价）：

| 指标 | 优选（★贴线） | 可贴（○） | 降权 / 不进池（×） |
|------|---------------|-----------|-------------------|
| **均偏黄**（\|价−黄线\|/黄线 的均值） | **≤ 0.25%** | ≤ 0.45% | **> 0.8%** |
| **最大偏黄**（段内最大 \|偏离\|） | **≤ 0.7%** | ≤ 1.2% | **> 1.8%** |
| **现偏黄**（此刻相对黄线） | 约 **−1%～+1%** | −1.5%～+1.5% | 持续 >2% 算已拉开 |
| **近窗振幅**（段内最高/最低） | **≤ 1.2%** 更佳 | 贴板苗 ≤ 2.5%；隔段苗 ≤ 1.2% | 振幅合格但绕黄线甩大 → 仍降权 |

排序口诀：**先比贴黄线，再比缩量**（不再用主线/是否涨停加权）。  
例：均偏 0.4%、振幅 1.6% 的「上下抖」**不如**均偏 0.15%、振幅 0.7% 的趴线票。

辅助：

- **日振幅过大**（如早盘已拉过一波，全日振幅 ≫ 近窗振幅）：近段若已贴黄，可留作 ○，但标注「早拉后贴」，防假横；日振幅很大且近段仍不贴黄 → 不进池。  
- 肉眼：白线几乎叠在黄线上磨 = 优；白线绕黄线明显波浪 = 差。

### 5.3 「正在形成」判定

| 条件 | 标准 |
|------|------|
| 市值 | **总市值 < 1000 亿** |
| 涨幅 | **今日涨幅 < 4%** |
| 距板 | **距涨停 > 3%**（快封板不要） |
| 横盘窗口 | 最近 **25～60 分钟**（隔段苗子可看 **≥45 分钟**） |
| 振幅 | 贴板苗：**≤ 2.5%**；隔段苗：**≤ 1.2%**（须同时过 **5.2 贴黄线**） |
| **贴黄线** | 见 5.2；**★优先，○次选，×不进** |
| **缩量横** | 横盘段分时量 **明显小于** 开盘前半小时或上一波拉升段（肉眼偏缩即可） |
| 仍在横盘态 | 现价相对横盘均价约 **-2%～+3.5%**；且现偏黄不宜过大（见 5.2） |
| 龙型标注 | 同第 2 节 → 卧 / 蛟 / 潜（盘中认大概，别抠百分比） |
| **抬头放量（升级）** | 仍先贴黄蓄势 → 破横盘上沿或抬离黄线，且量能放大 → 标「抬头中」，才重点盯 |
| 主线 / 曾涨停 | **不作为条件** |

两档：

- **A 档·横盘观察**：**贴黄线** + 窄横 + 缩量 → 挂着，不急  
- **B 档·抬头盯盘**：A 档出现抬头放量 → 才密集看（假突破：放量但剧烈甩离黄线又砸回，降级）

### 5.4 多久找一次（建议节奏）

横盘本身要二三十分钟才成型，**不必盯盘每一分钟**。

| 时段 | 动作 | 间隔 |
|------|------|------|
| **09:30–10:00** | 开盘噪声大，分时形态不稳，可不正式筛或只扫 1 次 | 可跳过或扫 1 次 |
| **10:00–11:30** | 上午主筛：建/刷 A 档观察池（按贴黄线排序） | 约 **20～30 分钟** 一轮 |
| **13:00–14:30** | 隔段冲板高发，继续刷池；B 档加密 | 约 **15～20 分钟** 一轮 |
| **14:30 后** | 尾盘冲动多、假突破多 | 只盯已有 B 档，**不再广筛** |
| **B 档出现后** | 单票跟分时 | 可 **5～10 分钟** 看一眼，或设股价/涨幅提醒 |

一句话：**广筛半小时一轮；票一抬头再加密。** 有提醒条件就设「突破横盘高点 / 涨幅阈值」，比徒手狂刷强。

### 5.5 盘中用法

```
全市场沪深主板扫描（禁止先按主线/题材手工缩名单）
    → 硬门槛：非ST、非科创/创业/北交、市值<1000亿、涨幅<4%、距板>3%；剔近板/一字
         → 不看主线、不看曾涨停
              → 贴黄线（★/○）+ 窄横 + 缩量 → A 档（卧/蛟/潜）
                   → 按贴黄紧密度截断约 10～20 只（若过多）
                        → 抬头 + 放量 → B 档加密盯
                             → 若最终封板，再用第 3 / 4 节确认
```

池内排序：**贴黄紧密度 ↓ → 缩量质量**。  
说明：盘中命中的是**形态苗子**，多数不会涨停；这是观察池，不是买卖信号。
