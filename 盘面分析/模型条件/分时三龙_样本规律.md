## 一、共性规则（10 只都满足）

1. **主板涨停**，且**非早盘秒板**（都有一段可见横盘再封）  
2. 封板前存在一段**窄幅横盘**，再**抬头**上板  
3. 横盘时长大约 **25～60 分钟**（样本中位约 34 分钟）  
4. 抬头段相对横盘段，分时量中位约 **1.4 倍**（偏放量抬头）  
5. **没有卧龙**命中；以缠绕均价的**蛟龙**为主  

---

## 二、两条路径（按模式拆）

### A. 贴板型（7/10）——盘中主力盯这个

| 特征 | 样本表现 |
|------|----------|
| 占比 | 7 只 |
| 横盘振幅 | 约 **1.8%～2.5%**（均值 ~2.0%；嘉诚偏紧 0.83%） |
| 抬头幅度 | 多数 **2%～4%** 即封；少数大抬头（嘉诚、中交） |
| 横→封间隔 | 几乎 **1 分钟内**接上（横完就打） |
| 横盘时长 | 多在 **24～35 分钟**（亚玛顿偏长 ~60 分钟） |
| 封板时段 | 上午少量；**午后尤其 13:30 后、14 点后**更多 |
| 龙型 | 蛟龙为主，2 只潜龙（中交、众生） |

**一句话：** 分时贴着均价窄晃二十多分钟 → 突然拉直线封板。

### B. 隔段型（3/10）——农心 / 杭氧 / 郑中

| 特征 | 样本表现 |
|------|----------|
| 占比 | 3 只 |
| 横盘振幅 | **更紧**，约 **0.4%～1.0%**（均值 ~0.75%） |
| 抬头幅度 | **大**，约 **10%～12%**（从横盘均价到涨停） |
| 横→封间隔 | **约 2～2.5 小时**（上午横完，午后才封） |
| 横盘时段 | 都在 **10:30～11:30 一带**收完横盘 |
| 封板时段 | 都在 **13:20～13:50** |
| 龙型 | 全是蛟龙 |

**一句话：** 上午先极度缩幅横住 → 不破位熬过午休 → 午后一波顶上板。

## 五、给盘中用的「样本版」口诀

```
先排除早封一字
→ 找 25～60 分钟窄横（贴均价，蛟/潜）
    ├─ 振幅 2% 左右、横完马上有加速 → 贴板苗（重点）
    └─ 振幅 <1%、上午横完不破 → 隔段苗（午后等二波）
         → 抬头时量比横盘明显大 → 升级盯盘
```

### 样本给出的量化印象（供对照，非硬阈值）

| 项目 | 贴板苗 | 隔段苗 |
|------|--------|--------|
| 振幅 | ≤2.5%（常见 1.8～2.5） | ≤1.2%（常见 <1） |
| 横盘结束→动 | 几乎立刻 | 可隔 2 小时+ |
| 抬头空间 | 小抬头也可能封 | 往往要较大空间才封 |
| 高发时段 | 午后贴板 | 上午横 + 13:20～14:00 封 |

## 六、样本里不太稳的点（别过度解读）

1. **相对开盘的「缩量横」**：这 10 只用「横盘均量 / 开盘均量」多数 >1（涨停日中段量并不一定比开盘小），更可靠的是 **抬头量 > 横盘量**。  
2. **卧龙**：本样本为 0，不能说没有，只能说近 5 日这批不是主流。  
3. 样本仅 10 只、5 个交易日，规律会随行情切换，需持续滚动验证。
