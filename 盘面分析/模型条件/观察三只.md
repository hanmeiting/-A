# 观察三只（性价比：距头 / 腰 / 脚越近越好）

> 在三模型命中池内经二次过滤后再筛约 **3 只**。不构成投资建议。  
> 总览见 [总结.md](./总结.md)

## 部位对照

每只按其所属模型量对应支撑，**不限模型、不强制头腰脚各一**；按性价比取全池最近的若干只。

| 部位 | 模型 | 支撑（参照位） |
|------|------|----------------|
| **头** | [金元宝](./金元宝.md) | 涨停日收盘价 |
| **腰** | [银元宝](./银元宝.md) | (涨停收 + 昨收) / 2 |
| **脚** | [汉堡包](./汉堡包.md) | 涨停前一日收盘价 |

## 排序（可切换）

1. **弹性优先（当前）**：小市值、近10日振幅高、股价偏低、距涨停空间大；贴头/腰/脚为辅  
2. **性价比优先**：`｜今日收 − 支撑｜ / 支撑` 越小越好（贴头/贴腰/贴脚）

## 豹子号剔除（玄学）

从锚定涨停日～今日，若任一交易日的 **开 / 高 / 低 / 收** 打出豹子号，则整只剔除。

常见形态：

- 全同：`6.66` / `8.88` / `11.11` / `22.22`  
- `AB.AB`：如 `12.12`、`40.40`  
- **小数点后两位相同**：如 `13.33`、`5.55`、`9.99`（**`.00` 整数价不算**）  
- 特殊：`13.14`

## 其它

**前高 / 压力位**：不做自动剔除，自行看图判断。

**重大负面公告硬剔除**（结合新闻/公告）：

- 预重整 / 重整 / 破产相关  
- 可能被实施退市风险警示、终止上市风险提示  
- 大额债务逾期、账户大范围冻结等经营危机类公告  

辅看：行业与个股近期催化（板块预喜、政策、订单等）；缩量；非大跌放量。

观察三只须同时过：**模型 → 无豹子 → 无重大利空 → 再比弹性/性价比与新闻质量**。
