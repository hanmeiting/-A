# 通用条件

> 金元宝 / 银元宝 / 汉堡包共用。不构成投资建议。  
> 总览见 [总结.md](./总结.md)

1. 近 **8 个交易日**（**不含今日**）有过涨停；锚定最近一次仍满足条件的涨停日  
2. **今日涨幅 < 3.5%**  
3. **沪深主板**；排除科创板 / 创业板 / 北交所  
4. **非 ST**  
5. **总市值 < 1000 亿**  
6. 支撑判定允许 **微破 ≤ 0.02 元（约 1～2 分钱）**；超过仍算跌破  
7. **区间高点回撤日距（关键）**  
   - 区间 = **锚定涨停日（含当天）～今日（含今天）**  
   - 在该区间内找出 **最高价**，以及打出该最高价的交易日（若多日同价，取**最近一次**）  
   - **计数方式（含首尾）**：创新高日 = **第 1 天**，其后每个交易日 +1，**今天必须是第 2 / 3 / 5 / 8 天**  
   - 例（交易日）：高点在昨 → 今天第 **2** 天；高点在前日 → 今天第 **3** 天 → 保留  
   - 反例：高点在 10/12、今天 10/15 → 第 **4** 天 → **剔除**（如乔治白）  
   - 说明：今日本身是区间新高 = 第 1 天，不在集合内，自然排除  

## 术语

| 符号 | 含义 |
|------|------|
| `涨停收` | 锚定涨停日收盘价 |
| `昨收` | **涨停日前一日**收盘价（≠ 今天的昨天） |
