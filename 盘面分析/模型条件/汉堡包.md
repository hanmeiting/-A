# 汉堡包模型

> 支撑最弱（脚）。须先满足 [通用条件.md](./通用条件.md)。不构成投资建议。  
> 总览见 [总结.md](./总结.md)

## 规则

在通用条件基础上：

1. **支撑位** = `昨收`（涨停前一日收盘价）  
2. 涨停日之后满足其一即可（均含微破 ≤ **0.02 元**）：  
   - 收盘不破支撑；或  
   - 当日跌破但当日收回；或  
   - 次日开盘收回  
3. **排除金元宝、银元宝名单**（三级互斥）  

## 在三级中的位置

支撑由强到弱：**金元宝 → 银元宝 → 汉堡包**。  
仅在未进金元宝、银元宝时归属本模型。
