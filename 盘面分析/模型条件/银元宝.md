# 银元宝模型

> 支撑居中（腰）。须先满足 [通用条件.md](./通用条件.md)。不构成投资建议。  
> 总览见 [总结.md](./总结.md)

## 规则

在通用条件基础上（介于金元宝与汉堡包之间）：

1. **支撑位** = **`(涨停收 + 昨收) / 2`**  
   - 即：涨停日收盘价与涨停前一日收盘价的算术平均  
   - 「昨收」= 涨停前一日收盘，**不是**今天的昨天  
2. **今日（最后一天）收盘** 不低于该均价（允许微破 ≤ **0.02 元**）  
3. **排除金元宝名单**（已是金元宝的不再进银元宝）  

## 在三级中的位置

支撑由强到弱：**金元宝 → 银元宝 → 汉堡包**。  
互斥：剔金元宝后归属；命中后不再进汉堡包。
