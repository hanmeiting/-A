# 金 / 银 / 汉堡包模型

> 三级支撑选股（头 / 腰 / 脚）。含共用门槛与互斥归属。不构成投资建议。  
> 总览见 [总结.md](./总结.md)

---

## 术语

| 符号 | 含义 |
|------|------|
| `涨停收` | 锚定涨停日收盘价 |
| `昨收` | **涨停日前一日**收盘价（≠ 今天的昨天） |

支撑由强到弱：**金元宝（头）→ 银元宝（腰）→ 汉堡包（脚）**。  
互斥归属：**先金 → 再银 → 最后汉堡包**（不重复）。

| 模型 | 支撑位 | 部位 |
|------|--------|------|
| **金元宝** | `涨停收` | 头 |
| **银元宝** | `(涨停收 + 昨收) / 2` | 腰 |
| **汉堡包** | `昨收` | 脚 |

---

## 一、通用条件（三模型共用）

1. 近 **8 个交易日**（**不含今日**）有过涨停；锚定最近一次仍满足条件的涨停日  
2. **今日涨幅 < 3.5%**  
3. **沪深主板**；排除科创板 / 创业板 / 北交所  
4. **非 ST**  
5. **总市值 < 1000 亿**  
6. 支撑判定允许 **微破 ≤ 0.02 元（约 1～2 分钱）**；超过仍算跌破  
7. **区间高点回撤日距（关键）**  
   - 区间 = **锚定涨停日（含当天）～今日（含今天）**  
   - 在该区间内找出 **最高价**，以及打出该最高价的交易日（若多日同价，取**最近一次**）  
   - **计数方式（含首尾）**：创新高日 = **第 1 天**，其后每个交易日 +1，**今天必须是第 2 / 3 / 5 / 8 天**  
   - 例（交易日）：高点在昨 → 今天第 **2** 天；高点在前日 → 今天第 **3** 天 → 保留  
   - 反例：高点在 10/12、今天 10/15 → 第 **4** 天 → **剔除**（如乔治白）  
   - 说明：今日本身是区间新高 = 第 1 天，不在集合内，自然排除  

---

## 二、金元宝（头 · 支撑最强）

须先满足通用条件。

1. **支撑位** = `涨停收`（锚定涨停日收盘价）  
2. 涨停日之后至今日，每日 **收盘** 不低于支撑位（允许下影；收盘微破 ≤ **0.02 元**）  
3. 判定看 **收盘**，不要求最低价不破支撑  
4. 命中后不再归入银元宝 / 汉堡包  

---

## 三、银元宝（腰 · 支撑居中）

须先满足通用条件；介于金元宝与汉堡包之间。

1. **支撑位** = **`(涨停收 + 昨收) / 2`**  
2. **今日（最后一天）收盘** 不低于该均价（允许微破 ≤ **0.02 元**）  
3. **排除金元宝名单**；命中后不再进汉堡包  

---

## 四、汉堡包（脚 · 支撑最弱）

须先满足通用条件。

1. **支撑位** = `昨收`（涨停前一日收盘价）  
2. 涨停日之后满足其一即可（均含微破 ≤ **0.02 元**）：  
   - 收盘不破支撑；或  
   - 当日跌破但当日收回；或  
   - 次日开盘收回  
3. **排除金元宝、银元宝名单**；仅未进金/银时归属本模型  

---

## 执行顺序

```
涨停池/K线 → 通用条件（含高点日距第 2/3/5/8 天）
    ├─ 金元宝（支撑=涨停收；此后每日收盘不破）
    ├─ 银元宝（支撑=均价；今日收盘不破；剔金）
    └─ 汉堡包（支撑=昨收；剔金+银）
         → 二次过滤 → 观察三只
```
