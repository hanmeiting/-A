## 三模型对比（支撑由强到弱）

记：`涨停收` = 锚定涨停日收盘价；`昨收` = **涨停前一日**收盘价。

| 模型 | 支撑位 | 相对位置 | 部位 |
|------|--------|----------|------|
| **金元宝** | `涨停收` | 最高 | 头 |
| **银元宝** | `(涨停收 + 昨收) / 2` | 中间 | 腰 |
| **汉堡包** | `昨收` | 最低 | 脚 |

互斥归属（由强到弱，不重复）：**先金元宝 → 再银元宝 → 最后汉堡包**。

---

## 执行顺序（建议）

```
涨停池/K线 → 通用条件（含高点日起算今天为第 2/3/5/8 天）
    ├─ 金元宝（支撑=涨停收；此后每日收盘不破）
    ├─ 银元宝（支撑=均价；今日收盘不破；剔金元宝）
    └─ 汉堡包（支撑=昨收；剔金元宝+银元宝）
         → 二次过滤（均线压制等；前高自行判断）
              → 弹性/性价比再筛 3 只观察

（并行/另线）分时三龙：全市场主板 → 市值/涨幅/距板硬门槛 → 贴黄横盘 → 抬头放量 → 涨停后确认
```

## 参数速查

| 参数 | 取值 |
|------|------|
| 涨停回看窗口 | **8** 交易日（不含今日） |
| 今日涨幅上限 | < 3.5% |
| 市值上限 | < 1000 亿 |
| 微破容差 | ≤ 0.02 元 |
| 区间高点→今天（含高点日=第1天） | 今天必须是第 **2 / 3 / 5 / 8** 天 |
| 金元宝支撑 | 涨停收 |
| 银元宝支撑 | (涨停收 + **涨停前一日收盘**) / 2；**只看今日收盘** |
| 汉堡包支撑 | **涨停前一日收盘** |
| 前高压力 | 自行看图，程序不剔 |
| 市场范围 | 沪深主板，非 ST，非科创/创业/北交 |
| 三级互斥 | 金元宝 ⊃ 银元宝 ⊃ 汉堡包（由强到弱归属） |
| 分时三龙贴板 | 振幅≤2.5%，抬头≥1.8%；贴板均偏>0.8%不计 |
| 分时三龙隔段 | 振幅≤1.2%，窗口≥45分钟，抬头≥5%；可弱贴黄 |
| 分时三龙贴黄分档 | ★≤0.25%；○≤0.45%；△≤0.8%均计入；隔段弱：均偏≤1.5%且最大偏≤1.8%亦计入 |
| 分时三龙市值 | **总市值 < 1000 亿** |
| 分时三龙涨幅 | **今日涨幅 < 4%** |
| 分时三龙距板 | **距涨停 > 3%**（快封板不要） |
| 分时三龙选池 | **默认全市场主板扫描**；不限主线/曾涨停；禁止先按题材缩名单 |
| 分时三龙排序 | **贴黄紧密度 → 缩量**（过硬门槛后再截断约 10～20 只） |
