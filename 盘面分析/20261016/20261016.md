## 二、涨幅靠前板块及原因

### 1. 国防军工 / 航空航天 / 导弹（今日主线 · 资金净流入最大）

- **板块表现**：国防军工约 **+4.5%**；航空装备、地面兵装约 **+6%**；导弹概念约 **+5%**；财联社口径国防军工主力净流入约 **27 亿**。
- **涨停 / 强势标的**：

| 标的 | 代码 | 表现 | 涨停/走强原因 |
|------|------|------|----------------|
| **晟楠科技 / 捷众科技** | 920006 / 920690 | **30cm 涨停** | 北交所军工弹性，板块情绪最强端 |
| **晨曦航空 / 华力创通 / 金盾股份 / 佳力奇** | 300581 等 | **20cm 涨停** | 航空/军工信息化/红外等跟涨 |
| **长城军工** | 601606 | **涨停** | 中兵系 + 地面兵装龙头情绪 |
| **航天晨光 / 新兴装备 / 长春一东 / 广东宏大** | 600501 等 | **涨停** | 导弹/军贸/装备链扩散 |
| **中科海讯 / 司南导航** | 300810 / 688592 | 大涨或涨停 | 航海装备、卫星导航跟主线 |

- **原因归纳**：
  1. **第十六届珠海航展**定档 **2026-12-07～13**，新型装备亮相 + 军贸窗口预期升温；
  2. **中东等地缘冲突**发酵，市场交易防空预警、低成本高效费比装备、军贸第二增长曲线；
  3. 板块 10 月以来偏弱、部分 ETF 昨创近一年低点，今日带有 **超跌反弹 + 事件催化** 双重驱动。
- **风险**：多为 **首板集中开火**，连板晋级率低（一板→二板约 13%）；若明日无法向中军（主机厂/电子）扩散，容易一日游。

### 与「观察三只」的关系（备忘）

今日主线是 **军工 / 飞行汽车**；金银汉堡包观察池（三维化学、返利科技、韶能股份等）偏 **业绩/事件回踩**，与今日攻击方向不一致——模型票表现平淡属风格错配，不等于支撑位逻辑当场失效；若破头/破腰且放量，再按模型做失效处理。
