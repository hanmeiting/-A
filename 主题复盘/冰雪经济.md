# A 股冰雪经济标的梳理（仅高弹性）

> 整理时间：2026-10-29  
> 主逻辑：雪季旺季前置（滑雪搜索/住宿预订暴增）→ 设备交运情绪龙点火 → 景区/IP 补涨确认  
> **只收录交易弹性偏高标的；低弹性跟风票（百货、普通文旅、钝化大票等）已剔除**  
> **仅研究梳理，不构成投资建议**

---

## 〇、怎么读

| 标签 | 含义 |
|------|------|
| **极高** | 小市值/高辨识度，易涨停、换手大，回撤也猛 |
| **高** | 常跟板或冲高，题材纯度够，能打波段 |
| **中高** | 有逻辑、有跟涨，盘子或纯度限制连板高度 |
| **纯** | 冰雪收入/客流直接相关 |
| **叠** | 制冷/液冷等交叉叙事，冰雪占比需验证 |
| **蹭** | 区域或业务能扯上，情绪时弹性仍够才收录 |

## 三、弹性排序（交易视角）

```
极高：冰山冷热 ≈ 龙江交通 ≈ 祥源文旅
 高 ：雪人集团 ≈ 晶雪节能 ≈ 大连圣亚
中高：长白山 ≈ 龙建股份 ≈ 元隆雅图 ≈ 三夫户外 ≈ 西域旅游
```

**盯盘优先级（延续日）**

1. **情绪确认**：冰山冷热 / 龙江交通 / 祥源文旅 —— 封板质量、换手是否继续天量  
2. **补涨确认**：长白山 / 大连圣亚 / 龙建股份 —— 从跟涨升至冲板/放量加速  
3. **装备扩散**：雪人集团、晶雪节能 —— 量能跟上且不掉队

## 四、复查结论（对照完整概念名单）

对照金股讯/连板网等冰雪产业成分（约 40–60 只）+ 今日涨幅扫描，结论：

| 结论 | 标的 | 说明 |
|------|------|------|
| **补进主池** | **龙建股份** | 今日跟涨+振幅够；漠河冰雪；此前误放「剔除」 |
| **有逻辑·弹性不够** | 天桥起重 | 天桥奥悦供滑雪场设备；今日仅 +1.5%，辨识度/股性弱于核心装备 |
| **有逻辑·弹性不够** | 中工国际 | 北起院滑雪索道；盘子大、今日几乎平盘 |
| **观察·不进** | 奥雅股份 | 今日振幅>12% 但收平；文旅景观设计蹭，方向不稳 |
| **今日强·非本题材** | 华利集团、开润股份 | 户外鞋服/箱包，非冰雪成分，勿误收 |

### 已剔除（弹性低 / 钝化 / 纯度低）

| 类型 | 代表 | 剔除理由 |
|------|------|----------|
| 制冷大票钝化 | 冰轮环境、盾安环境 | 今日逆势跌或跟涨钝 |
| 户外钝化 | 探路者 | 同日大跌，未共振 |
| 赛事/培训弱 | 中体产业、华策影视、凯文教育 | 波动小或冰雪占比极低 |
| 弱映射文旅 | 峨眉山A、西藏旅游、天府文旅、岭南控股、凯撒旅业、三特索道、九华旅游 | 纯度低且弹性一般 |
| 区域商业 | 武商集团、欧亚集团、中兴商业 | 哈尔滨商业弱映射 |
| 健身器材 | 英派斯、康力源、欧圣电气、舒华体育 | 关联弱、波动一般 |
| 边缘装备 | 天桥起重、中工国际、通达创智、钱江摩托 | 能扯上，高潮才脉冲 |
| 其他蹭 | 吉林化纤、锋尚文化、流金科技、东南网架、元创股份、哈空调 | 今日跌或弹性/纯度不足 |

## 五、风险分层

| 类型 | 说明 |
|------|------|
| 情绪 vs 业绩 | 冰山冷热冰雪收入未确认；设备票多靠「能用在雪场」叙事 |
| 季节节奏 | 秋末炒预期 → 开板看客流 → 春节前后易退潮 |
| 高换手回撤 | 涨停日换手近 40% 类（冰山冷热）次日分歧大 |
| 纯度陷阱 | 真正吃滑雪客流的是长白山/圣亚；祥源偏雾凇/南方赏雪，弹性高但冰雪收入占比有限；设备票兑现更慢 |
