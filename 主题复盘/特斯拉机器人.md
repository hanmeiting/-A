# A 股特斯拉人形机器人（Optimus / T 链）标的梳理

> 整理时间：2026-09-28  
> 主逻辑：Optimus 量产审厂 + 千台级订单 → 汽车 T 链供应商切入机器人执行器/控制器  
> 催化时点：2026-09-16/17 宁波等地审厂；约 5000 台订单传闻；规划 2026 年下线约 5 万台  
> **仅研究梳理，不构成投资建议**

---

## 〇、先看清：什么叫「和特斯拉有关系」

| 档位 | 含义 | 怎么用 |
|---|---|---|
| ★★★ | 汽车特斯拉供应商 + 本轮审厂/订单被主流媒体点名 | 真正可算 T 链核心 |
| ★★ | 有厂审/送样/定点类报道，或明确在审厂传闻名单 | 次核心，需持续验证 |
| ★ | 同环节（减速器/丝杠/电机等），技术对口但未确认供 T | **赛道相关 ≠ 已供特斯拉** |
| ☆ | 机器人概念 / 间接持股故事 | **不要算进 T 链** |

**重要**：特斯拉未官宣完整供应商名单；「审厂/订单」多为产业链与媒体消息。

```
关节怎么动？
├── 旋转关节 → 减速器（谐波：绿的｜RV：双环）
├── 直线关节 → 丝杠（五洲、北特）+ 轴承（五洲等）
├── 手指灵巧 → 空心杯（鸣志）+ 力传感（柯力）+ 皮肤（福莱/均胜）
```

## 四、本轮催化与盘面分层（2026-09 中下旬）

### 催化要点

1. 特斯拉向供应商下发约 **5000 台** Optimus 量产级订单（产业链消息）  
2. **9/16–17** 起宁波等地新一轮量产审厂；覆盖长三角  
3. 审厂重点点名：**拓普、三花、均胜**；此前名单还曾出现荣泰、新泉等  
4. 规划口径：2026 年下线约 **5 万台**（多次跳票过，需动态跟踪）

### 9/17 前后盘面（示例）

| 分层 | 标的表现 | 含义 |
|---|---|---|
| 已高潮 | 均胜涨停 | 控制器 + 具身智能情绪打满 |
| 半高潮 | 拓普约 +4%、长盈等跟涨 | 部分计价 |
| 相对未充分 | 三花约 +2.7%；荣泰/新泉/五洲/鸣志等若未大涨 | 同源扩散可跟踪方向 |

## 五、风险（必读）

1. **名单未官宣**：审厂 ≠ 独家份额；订单规模与份额不确定  
2. **收入占比仍小**：如拓普机器人执行器收入相对主业可忽略，估值主要靠远期故事  
3. **量产多次跳票**：2026 年板块整体曾长期偏弱，行情可能一日游  
4. **勿混淆**：宇树间接持股、厨房机器人参股 ≠ 特斯拉 Optimus 链  
5. **环节纯 ≠ 客户纯**：减速器/丝杠龙头不等于已进入 T 链
