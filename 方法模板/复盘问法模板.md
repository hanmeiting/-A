# A 股复盘 / 潜在机会挖掘 —— 问法模板

> 用途：以后复盘直接复制对应模板提问，逼出「表面涨幅榜」之外的**二级催化、产业链扩散、潜在机会**。  
> 核心区别：**领涨是什么** = 结果表；**钱在买什么故事、还能传到谁** = 机会表。  
> **仅研究辅助，不构成投资建议。**

---

## 一、为什么要换问法

| 问法类型 | 典型问题                     | AI 会给出的东西                            | 容易漏掉的                                      |
| -------- | ---------------------------- | ------------------------------------------ | ----------------------------------------------- |
| 结果表   | 领涨前五是什么？因为什么？   | 一级行业/概念涨幅榜 + 主流媒体催化         | 个股背后的细分题材（如均胜 → 特斯拉机器人链路） |
| 机会表   | 钱在买什么故事？还能传到谁？ | 表面催化 vs 真实情绪、二三级扩散、风险分层 | ——                                              |

**教训案例（2026-09-17）**  
只问领涨前五 → 得到汽车整合、种业、医药。  
若追问强势个股真实题材 → 才能挖出均胜电子背后的**具身智能 / 特斯拉 Optimus 审厂+订单**链路。

## 二、日常复盘总模板（首选，直接复制）

```
做今日（YYYY-MM-DD）A股复盘：不要只列领涨板块。

请按下面结构回答：
1. 指数与主线（一级行业涨幅前5 + 概念涨幅前5）
2. 每条主线的【表面催化】vs【更细的情绪/产业催化】
3. 强势龙头拆解：为什么是它？资金在买什么故事？
4. 潜在机会链：这条逻辑还能扩散到哪些二三级方向/环节？给出可跟踪的标的类型（不必荐股）
5. 风险：哪些是纯情绪、业绩占比极小、不宜当真的？

额外要求：
- 优先看：公告/订单、产业链传导、AH同步异动、概念扩散、资金净流入居前但涨幅不大的环节
- 对涨停/大涨个股，强制区分「板块贝塔」和「细分题材」
```

## 三、专项追问模板

### 1. 只要机会链，不要涨幅榜

```
今天涨得好的方向里，真正可扩散、可跟的二三级机会是什么？
别只报行业名，拆到：具体催化 → 传导环节 → 可跟踪标的类型。
```

### 2. 强势个股：情绪定价 vs 产业定价

```
XX（代码）今天大涨/涨停，表面板块是什么？
盘中或港股同步强势的真正题材是什么？
有没有机器人、华为车、算力、出海、整合等更细的链路？
这条链上下游还有谁可能受益？哪些只是情绪泡沫？
```

### 3. 错过龙头之后：同源未充分定价

```
如果我错过了今天的龙头（列出：XXX），
同源催化下还有哪些还没充分定价、或下周可跟踪的方向/环节？
请区分：已高潮 / 跟涨中 / 尚未启动。
```

### 4. 单条主线深挖

```
今天主线是【XX板块】，请拆：
1. 触发公告/消息原文要点
2. 资金真正买的故事（可能不止一个）
3. 产业链上中下游谁最受益、谁只是蹭
4. 二三级扩散方向（材料、设备、软件、出海等）
5. 需要证伪的关键点（订单占比、量产节奏、政策不确定性）
```

---

## 四、固定漏斗关键词（可贴在任何问题末尾）

```
优先看：公告/订单、产业链传导、AH同步异动、概念扩散、
资金净流入居前但涨幅不大的环节；
强制输出：表面催化 vs 真实题材 vs 可扩散机会 vs 风险。
```

---

## 五、自检清单（问完后看回复有没有这些）

- [ ] 有没有「表面原因」和「更细催化」两层？
- [ ] 强势个股有没有拆到细分概念（而不只是所属一级行业）？
- [ ] 有没有「还能传到谁」的二三级机会？
- [ ] 有没有标明「情绪 vs 业绩占比/订单落地」？
- [ ] 有没有「已涨透 / 可跟踪 / 高风险蹭」分层？

若缺任意一项 → 追问：`请补全第X条，尤其是潜在机会链和风险分层。`

## 六、一句话极简版（赶时间）

```

```
