## 分类原则（以后往哪放）

1. **长逻辑赛道研究**（有上下游、映射、跟踪指标）→ 独立一级目录，如 `科技牛/`、`创新药/`
2. **阶段性主题高潮复盘**（催化驱动、标的列表）→ `主题复盘/`
3. **短线情绪博弈** → `情绪题材/`
4. **每日盘面与交易模型** → `盘面分析/`
5. **可复用方法** → `方法模板/`

赛道目录建议统一子结构：

```
某赛道/
├── 总览.md
├── 交互浏览.html   （可选）
├── 细分/           （产业链拆解）
└── 标的复盘/       （深度个股/子板块复盘）
```
