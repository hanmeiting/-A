## 一、产业链一句话

```
树脂 + 电子布 + HVLP铜箔  →  CCL覆铜板  →  PCB板厂
                              钻针（耗材，打孔用）
```

| 阶段 | 炒的本质 | 代表 |
|---|---|---|
| 2025 前后 | 订单 / 客户叙事 | 胜宏等：谁接到英伟达、AI 服务器板 |
| 2026 上半年至今 | 涨价 / 供给短缺 | 宏和、金安国纪、生益：布、CCL、箔、树脂提价 |
| 夹杂全程 | 扩产、国产替代、跨界 | 钻针、设备、并购票（偏跟风） |

**近段核心：涨价（材料通胀）市，AI 是需求背景。**

## 七、历史涨幅与炒作顺序

### 阶段表现

| 阶段 | 谁涨得好 |
|---|---|
| 故事期（约 2025） | **胜宏** 等 AI 板厂 |
| 涨价期（约 2026 上半年） | **宏和、金安国纪、国际复材** 等上游 |
| 跟风期 | 钻针 / 小盘板厂 / 跨界题材 |
| 兑现期 | **沪电、深南、生益系** 等业绩稳的 |

### 常见轮动路径

```
① 板厂龙头（故事）胜宏 → 沪电/深南/广合
② CCL 涨价函 → 生益、金安、南亚、华正
③ 更上游 → 电子布 / HVLP / 树脂
④ 耗材设备 → 钻针、钨、大族数控
⑤ 小盘正宗 + 纯题材 → 中京、超声、普林、跨界…
```

产业物理顺序：`电子布 / HVLP / 树脂涨价 → CCL 涨价 → PCB 板厂提价`

### 若再起行情（主观推测）

1. 供给仍紧的上游：HVLP、高端树脂、高端电子布  
2. 新场景细分板厂：光模块/mSAP（红板）、载板（深南/兴森）  
3. 扩产耗材设备：鼎泰高科、民爆、大族数控  
4. 尾声小盘跟风：中京、超声、普林（风险大）  

**不太会简单复刻：** 胜宏式认知差十倍、全板块普涨、果汁跨界成主线。
