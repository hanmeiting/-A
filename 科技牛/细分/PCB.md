## 一句话

AI 服务器与交换机 **高多层板** 是主战场；**高速 CCL** 最先敏感。

---

## 观察优先级

| 优先级 | 环节 | A股常见映射举例 |
|---|---|---|
| 一阶 | 高多层服务器/交换机PCB | 沪电股份、深南电路、生益电子、胜宏科技、景旺电子、世运电路 |
| 一阶上游 | 高速CCL | 生益科技、华正新材、南亚新材、金安国纪 |

## 产业链拆解

### 1. 高多层服务器/交换机PCB（中游主战场 · AI相关度最强）

| 项目 | 内容 |
|---|---|
| 逻辑 | 层数与价值量随AI服务器上修，量价最直接 |
| 产品规格 | 18–30+层服务器主板、交换机高速板、加速卡/网卡板 |
| 常见映射 | 沪电股份、深南电路、生益电子、胜宏科技、景旺电子、世运电路 |
| 跟踪指标 | AI服务器出货、高多层稼动率、AI板占比、毛利率、ASP |
| 备注 | 看海外大客户认证与AI收入占比 |

### 2. 高速CCL（上游 · AI相关度最强）

| 项目 | 内容 |
|---|---|
| 逻辑 | 低Dk/Df高速材料是AI板性能瓶颈；材料涨价常领先PCB厂利润改善 |
| 产品规格 | 高速CCL、高频CCL、M6/M7/M8等级、半固化片 |
| 常见映射 | 生益科技、华正新材、南亚新材、金安国纪 |
| 跟踪指标 | 高速CCL均价/价差、库存天数、高速产品占比、树脂/电子布成本、海外认证 |
| 备注 | 材料涨价是板厂景气的领先信号之一 |

### 3. 电子铜箔 HVLP（上游 · AI相关度强）

| 项目 | 内容 |
|---|---|
| 逻辑 | 高多层、高速板需要更细、更低粗糙度铜箔 |
| 常见映射 | 嘉元科技、德福科技、铜冠铜箔、诺德股份 |
| 跟踪指标 | 电子箔加工费、HVLP占比、开工率、铜价、CCL厂补库节奏 |
| 备注 | **务必区分电子铜箔 vs 锂电铜箔** |

### 4. 封装载板 / 类载板（中游旁支 · AI相关度强）

| 项目 | 内容 |
|---|---|
| 逻辑 | 先进封装、高速交换带动ABF/BT载板；壁垒高于普通PCB |
| 常见映射 | 深南电路、兴森科技 |
| 跟踪指标 | CoWoS/先进封装产能、ABF供需、载板稼动率、新规格导入 |
| 备注 | 与服务器PCB不同赛道，详见 [先进封装.md](./先进封装.md) |

### 5. PCB设备 / 钻针 / 电子布（上游配套 · AI相关度中）

| 项目 | 内容 |
|---|---|
| 逻辑 | 高多层扩产带动钻孔、压合、AOI及电子布需求；偏滞后 |
| 常见映射 | 大族数控、鼎泰高科、中国巨石、宏和科技 |
| 跟踪指标 | 板厂CapEx、设备订单、钻针消耗、电子布价格 |
| 备注 | 确认扩产后才有像样订单弹性 |

### 6. HDI / 消费+汽车PCB（需求底盘 · AI相关度弱）

| 项目 | 内容 |
|---|---|
| 逻辑 | 传统消费电子、汽车电子需求底盘；不是本轮AI主升浪核心 |
| 常见映射 | 鹏鼎控股、东山精密 |
| 跟踪指标 | 手机出货、PC排产、汽车电子渗透、HDI稼动率 |
| 备注 | 讲AI故事时权重应下调 |

## 上下游简图

```
上游：电子铜箔(HVLP) → 树脂/电子布 → 覆铜板CCL
        ↓
中游：高多层PCB / HDI / 封装载板
        ↓
下游：AI服务器主板 / 交换机 / 光模块板 / 加速卡
```

## 指标时间轴

| 时效 | 看什么 | 含义 |
|---|---|---|
| 领先3–6月 | 北美/国内云厂CapEx、AI服务器ODM排产 | 决定板厂订单上限 |
| 领先1–3月 | 高速CCL价格与库存、铜箔加工费 | 材料涨价常先于板厂利润 |
| 同步 | 高多层稼动率、AI板占比、毛利率 | 验证景气是否兑现到财报 |
| 滞后 | PCB设备订单、扩产落地 | 确认中期产能与竞争格局 |
| 风险 | 消费电子拖累、价格战、客户集中、认证失败 | 辨认假突破与真景气 |

---

## 检查清单

1. 云厂CapEx / ODM排产是否还在上修？
2. 高速CCL是否涨价或去库结束？
3. 板厂AI业务占比与毛利率是否同步改善？
4. 高多层产能是否紧张（交期拉长/加急单）？
5. 有没有被消费电子或价格战稀释掉AI弹性？
