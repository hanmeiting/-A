# 光通信 / CPO · A股映射 + 跟踪指标

> 整理时间：2026-10-16  
> 必要程度：核心刚需  
> **仅研究梳理，不构成投资建议**

---

## 一句话

主战场是 **800G / 1.6T 光模块**；CPO/硅光是下一代。A股光模块映射全球最清晰。

| 优先级 | 环节 | A股常见映射举例 |
|---|---|---|
| 一阶 | 高速光模块 | 中际旭创、新易盛、天孚通信、光迅科技 |
| 一阶上游 | 光器件/光芯片 | 源杰科技、长光华芯、仕佳光子、联特科技 |

---

## 产业链拆解

### 1. 高速光模块 800G/1.6T（中游主战场 · AI相关度最强）

| 项目 | 内容 |
|---|---|
| 逻辑 | GPU集群互联放量最直接受益。北美云厂是核心客户 |
| 常见映射 | 中际旭创、新易盛、光迅科技、华工科技、剑桥科技 |
| 跟踪指标 | 800G出货、1.6T送样/订单、云厂CapEx、毛利率、产能与良率 |
| 备注 | 看客户结构（微软/谷歌/Meta/亚马逊）与速率升级节奏 |

### 2. 光器件 / 光引擎 / 无源（中上游 · AI相关度最强）

| 项目 | 内容 |
|---|---|
| 逻辑 | 模块里价值量和壁垒所在；天孚等偏组件平台 |
| 常见映射 | 天孚通信、光库科技、太辰光 |
| 跟踪指标 | 高速产品占比、单模块价值量、客户导入、产能利用率 |
| 备注 | 常与模块厂景气共振，盈利质量看产品结构 |

### 3. 光芯片 / 激光器（上游核心 · AI相关度强）

| 项目 | 内容 |
|---|---|
| 逻辑 | EML/硅光芯片决定速率与功耗；国产替代空间大、认证长 |
| 常见映射 | 源杰科技、长光华芯、仕佳光子、光迅科技（部分自研） |
| 跟踪指标 | 高速光芯片出货、国产替代率、良率、大客户认证、存货 |
| 备注 | 壁垒高，短期体量未必赶上模块厂弹性 |

### 4. CPO / 硅光 / LPO（下一代 · AI相关度强）

| 项目 | 内容 |
|---|---|
| 逻辑 | 降功耗提密度的演进方向；商业化节奏决定主题弹性 |
| 常见映射 | 中际旭创等模块厂方案、光库科技、交换机/硅光合作标的 |
| 跟踪指标 | CPO试点规模、LPO渗透、功耗指标、交换机厂商roadmap |
| 备注 | 主题强于短期收入；别把故事当已兑现订单 |

### 5. 高速连接器 / 铜缆过渡（配套 · AI相关度中）

| 项目 | 内容 |
|---|---|
| 逻辑 | 短距仍可用DAC/铜连接；机柜内互联增量 |
| 常见映射 | 鼎通科技、意华股份、沃尔核材（高速线缆相关） |
| 跟踪指标 | DAC/AOC出货、单柜连接价值量、800G配套放量 |
| 备注 | 过渡方案，长期份额可能被光替代，但中期有量 |
