# 电源 / 电力 / 高压配电 · A股映射 + 跟踪指标

> 整理时间：2026-10-16  
> 必要程度：强配套

## 一句话

算力烧的是电；PSU、HVDC、变压器、功率器件都是约束环节。

---

## 观察优先级

| 优先级 | 环节 | A股常见映射举例 |
|---|---|---|
| 一阶 | 服务器电源/钛金PSU | 欧陆通、中恒电气、科华数据、动力源 |
| 一阶 | 变压器/配电 | 特变电工、中国西电、金盘科技、三变科技 |
| 二阶 | 功率半导体 | 斯达半导、宏微科技、东微半导、新洁能 |
| 三阶 | 线缆/母线/UPS | 宝胜股份、许继电气、科士达 |

---

## 产业链拆解

### 1. 服务器电源 / HVDC（中游 · AI相关度最强）

| 项目 | 内容 |
|---|---|
| 逻辑 | 单柜功率跃升推高高效电源与高压直流方案 |
| 常见映射 | 欧陆通、中恒电气、动力源、科华数据 |
| 跟踪指标 | 单柜功率、钛金电源出货、HVDC渗透、云厂电源规格 |
| 备注 | 规格升级比单纯出货量更重要 |

### 2. 变压器 / 开关柜 / 电网侧（电力基建 · AI相关度强）

| 项目 | 内容 |
|---|---|
| 逻辑 | 智算中心落地受变压器交期与市电容量约束 |
| 常见映射 | 特变电工、中国西电、金盘科技、三变科技、思源电气 |
| 跟踪指标 | 变压器交期、订单排产、硅钢/铜成本、数据中心项目 |
| 备注 | AI是增量需求之一，还要看电网与出口订单 |

### 3. 功率半导体 Si/SiC（上游器件 · AI相关度强）

| 项目 | 内容 |
|---|---|
| 逻辑 | 电源转换效率与功率密度依赖功率器件 |
| 常见映射 | 斯达半导、宏微科技、东微半导、新洁能、扬杰科技 |
| 跟踪指标 | 服务器电源规格、SiC渗透、工业与新能源需求、库存价格 |
| 备注 | 需求多领域共振，AI占比需单独拆 |

### 4. UPS / 储能 / 线缆（配套 · AI相关度中）

| 项目 | 内容 |
|---|---|
| 逻辑 | 机房可靠性与备电；线缆随配电扩容 |
| 常见映射 | 科士达、科华数据、宝胜股份、汉缆股份 |
| 跟踪指标 | IDC开工、UPS订单、绿电配套、铜价 |
| 备注 | 稳健配套，弹性通常弱于液冷与服务器 |

## 上下游简图

```
上游：矽钢片·铜材 / 功率半导体 / 磁性元件·电容 / 绝缘线缆
        ↓
中游：服务器PSU·钛金电源 / HVDC·母线槽 / 变压器·开关柜 / UPS
        ↓
下游：数据中心配电 → AI机柜供电 → 园区电网扩容 → 算电协同
```

## 指标时间轴

| 时效 | 看什么 | 含义 |
|---|---|---|
| 领先 | 智算项目立项、单柜功率roadmap | 定电力需求 |
| 同步 | 电源/变压器订单与交期 | 瓶颈验证 |
| 确认 | HVDC规模化、变压器短缺持续 | 逻辑强化 |
| 风险 | 铜价、硅钢、产能过剩 | 利润波动 |
