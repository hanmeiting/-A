# AI 算力芯片 · A股映射 + 跟踪指标

> 整理时间：2026-10-16  
> 必要程度：核心刚需  
> **仅研究梳理，不构成投资建议**

---

## 一句话

海外定生态，国产看替代；A股很少直接映射高端GPU，更多看服务器、配套与国产算力。

---

## 观察优先级

| 优先级 | 环节 | A股常见映射举例 |
|---|---|---|
| 一阶 | 国产算力芯片/模组 | 海光信息、寒武纪、龙芯中科等 |
| 一阶配套 | AI服务器整机 | 工业富联、中科曙光、浪潮信息、紫光股份 |
| 二阶 | 芯片设计/IP/EDA周边 | 芯原股份、华大九天、广立微、概伦电子 |
| 三阶 | 先进封装与材料配套 | 见 [先进封装.md](./先进封装.md) |

---

## 产业链拆解

### 1. 国产AI芯片 / GPU / NPU（中游核心 · AI相关度最强）

| 项目 | 内容 |
|---|---|
| 逻辑 | 训练/推理芯片本体。A股以国产替代为主，生态与良率是关键 |
| 常见映射 | 海光信息、寒武纪、龙芯中科、景嘉微（偏图形） |
| 跟踪指标 | 大客户订单、推理/训练芯片出货、软件生态成熟度、毛利率、库存与流片节奏 |
| 备注 | 高端训练仍高度依赖海外GPU；A股弹性更多来自国产导入节奏 |

### 2. AI服务器 / 整机代工（下游 · AI相关度最强）

| 项目 | 内容 |
|---|---|
| 逻辑 | 芯片落地的销售形态。云厂与政企招标能见度高 |
| 常见映射 | 工业富联、中科曙光、浪潮信息、紫光股份、拓维信息 |
| 跟踪指标 | 云厂CapEx、AI服务器出货、国产芯片搭载率、毛利率、交付周期 |
| 备注 | 订单强，但利润率看供应链与竞争 |

### 3. 板卡 / 模组 / 互联配套（中游配套 · AI相关度强）

| 项目 | 内容 |
|---|---|
| 逻辑 | 加速卡、OAM模组、高速连接器等把芯片做成可部署单元 |
| 常见映射 | 华丰科技、鼎通科技、瑞可达等 |
| 跟踪指标 | 加速卡出货、连接器单机价值量、认证进度、产能利用率 |
| 备注 | 连接器常与服务器/液冷一起看 |

### 4. EDA / IP / 设计服务（上游 · AI相关度中）

| 项目 | 内容 |
|---|---|
| 逻辑 | 造芯必备工具链；国产替代长逻辑，短弹性弱于硬件放量 |
| 常见映射 | 华大九天、广立微、概伦电子、芯原股份 |
| 跟踪指标 | 国产EDA导入、晶圆厂/设计公司CapEx、新工具验证、经常性收入占比 |
| 备注 | 偏长期国产替代，不是景气脉冲主线 |

---

## 上下游简图

```
上游：EDA / IP / 先进制程代工 / 设备材料
        ↓
中游：AI GPU / ASIC / NPU（海外主导 + 国产替代）
        ↓
下游：AI服务器整机 → 云厂商/政企智算集群 → 模型训练推理
```

---

## 指标时间轴

| 时效 | 看什么 | 含义 |
|---|---|---|
| 领先 | 云厂CapEx、国产大模型招采 | 决定算力需求上限 |
| 同步 | 芯片出货、服务器交付、ASP | 验证景气兑现 |
| 滞后 | 软件生态、生态伙伴数量 | 决定国产可持续份额 |
| 风险 | 出口管制、生态割裂、价格战 | 业绩与估值双杀点 |

---

## 检查清单

1. 云厂/政企算力预算是否还在加？
2. 国产芯片是否进入规模化推理部署？
3. 整机厂AI服务器收入占比与毛利？
4. 有没有被出口管制或供应链卡死？
