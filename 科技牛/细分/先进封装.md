# 先进封装 · A股映射 + 跟踪指标

> 整理时间：2026-10-16  
> 必要程度：核心刚需  
> **仅研究梳理，不构成投资建议**

---

## 一句话

CoWoS 把 GPU+HBM 拼起来；A股看载板、封测、设备材料，而不是台积电本身。

---

## 观察优先级

| 优先级 | 环节 | A股常见映射举例 |
|---|---|---|
| 一阶 | 封装载板/类载板 | 深南电路、兴森科技 |
| 一阶 | 先进封测 | 长电科技、通富微电、华天科技 |
| 二阶 | 键合/封装设备与材料 | 华海清科、拓荆科技、芯源微、长川科技 |
| 三阶 | ABF/材料上游 | 有机基板材料、树脂相关 |

---

## 产业链拆解

### 1. 先进封测 2.5D/Chiplet（中游 · AI相关度最强）

| 项目 | 内容 |
|---|---|
| 逻辑 | 承接AI芯片封装增量；看谁拿到大客户先进封装订单 |
| 常见映射 | 长电科技、通富微电、华天科技、晶方科技 |
| 跟踪指标 | 先进封装收入占比、大客户导入、稼动率、资本开支、毛利率 |
| 备注 | 真正CoWoS产能仍集中海外/台积电体系，A股看增量份额 |

### 2. 封装载板（上游关键 · AI相关度最强）

| 项目 | 内容 |
|---|---|
| 逻辑 | ABF载板紧缺时常成瓶颈；认证壁垒高 |
| 常见映射 | 深南电路、兴森科技、崇达技术（部分） |
| 跟踪指标 | 载板稼动率、ABF供需、新规格认证、ASP、库存 |
| 备注 | 与PCB主业要分开估值：载板周期和服务器板周期不完全同步 |

### 3. 封装设备 / 前道延伸（上游铲子 · AI相关度强）

| 项目 | 内容 |
|---|---|
| 逻辑 | 扩产带来键合、研磨、电镀、检测设备需求 |
| 常见映射 | 华海清科、拓荆科技、芯源微、长川科技 |
| 跟踪指标 | 封测厂CapEx、设备订单、国产替代验证、交货周期 |
| 备注 | 订单滞后于封装景气确认 |

### 4. 封装材料（上游 · AI相关度中）

| 项目 | 内容 |
|---|---|
| 逻辑 | 塑封料、球焊丝、底部填料、光刻胶等随先进封装升级 |
| 常见映射 | 华海诚科、德邦科技、安集科技、雅克科技 |
| 跟踪指标 | 材料验证导入、单芯片材料用量、客户扩产、毛利率 |
| 备注 | 长逻辑国产替代，短弹性看导入节点 |

## 上下游简图

```
上游：硅中介层 / ABF载板 / 键合设备 / 封装材料
        ↓
中游：CoWoS·InFO·SoIC / Chiplet拼装 / HBM堆叠 / OSAT
        ↓
下游：AI GPU成品 → 高性能ASIC → 高端服务器芯片
```

---

## 指标时间轴

| 时效 | 看什么 | 含义 |
|---|---|---|
| 领先 | CoWoS扩产、GPU/HBM出货指引 | 定封装需求 |
| 同步 | 载板稼动、封测先进封装收入 | A股验证 |
| 滞后 | 设备材料订单 | 扩产确认 |
| 风险 | 扩产过度、技术路线变化、客户转移 | 利用率下行 |

---

## 检查清单

1. 先进封装产能是否仍紧？
2. 载板交期/价格是否紧张？
3. 封测厂先进封装占比提升了吗？
4. 只是主题还是已经进财报？
