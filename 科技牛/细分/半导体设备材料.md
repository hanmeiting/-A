# 半导体设备 / 材料 / 特气 · A股映射 + 跟踪指标

> 整理时间：2026-10-16  
> 必要程度：核心刚需

造芯的铲子；看全球+国内晶圆厂扩产，以及国产替代验证节点。

## 产业链拆解

### 1. 前道工艺设备（设备核心 · AI相关度最强）

| 项目 | 内容 |
|---|---|
| 逻辑 | 刻蚀、薄膜、清洗、涂胶显影等直接受益于晶圆厂扩产 |
| 常见映射 | 北方华创、中微公司、拓荆科技、盛美上海、芯源微、华海清科 |
| 跟踪指标 | 晶圆厂CapEx、国产设备中标、在手订单、验证平台数、毛利率 |
| 备注 | 光刻机仍高度受限，其他环节国产化推进更快 |

### 2. 量检测 / 后道测试（设备 · AI相关度强）

| 项目 | 内容 |
|---|---|
| 逻辑 | 先进制程与封装对检测需求上升 |
| 常见映射 | 中科飞测、精测电子、长川科技、华峰测控 |
| 跟踪指标 | 检测设备订单、存储/逻辑厂扩产、国产替代率 |
| 备注 | 与前道设备同周期，略偏验证滞后 |

### 3. 电子材料 / 特气 / 光刻胶（材料 · AI相关度最强）

| 项目 | 内容 |
|---|---|
| 逻辑 | 扩产即耗材；认证长，一旦导入粘性强 |
| 常见映射 | 华特气体、南大光电、晶瑞电材、安集科技、雅克科技、彤程新材 |
| 跟踪指标 | 材料验证层级、国产化率、晶圆厂开工、产品单价与毛利 |
| 备注 | 看「能不能进线」比看主题更重要 |

### 4. 硅片 / 靶材 / 零部件（上游底座 · AI相关度强）

| 项目 | 内容 |
|---|---|
| 逻辑 | 硅片是最大耗材之一；精密零部件决定设备交付能力 |
| 常见映射 | 沪硅产业、立昂微、江丰电子、正帆科技、新莱应材、英杰电气 |
| 跟踪指标 | 12寸硅片供需、靶材导入、零部件国产化、设备厂排产 |
| 备注 | 硅片偏全球周期，零部件偏国产替代 |

## 上下游简图

```
上游：精密零部件 / 特种钢材陶瓷 / 基础化学品与矿产
        ↓

下游：晶圆厂扩产 / 存储厂扩产 / 先进封装产线
```

## 指标时间轴

| 时效 | 看什么 | 含义 |
|---|---|---|
| 领先 | 全球/国内晶圆厂CapEx指引 | 定设备年景 |
| 同步 | 招标中标、在手订单 | 业绩可见度 |
| 滞后 | 材料放量、重复订单 | 替代兑现 |
| 风险 | 扩产推迟、验证失败、地缘摩擦 | 订单真空 |

## 检查清单

1. 晶圆厂资本开支是否还在加？
2. 设备是一次性订单还是重复采购？
3. 材料到了几级验证？
4. 存储厂与逻辑厂谁在扩？
