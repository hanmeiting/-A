# 存储（HBM / DRAM / NAND）· A股映射 + 跟踪指标

> 整理时间：2026-10-16  
> 必要程度：核心刚需  
> **仅研究梳理，不构成投资建议**

---

## 一句话

HBM 是 AI 卡命门但本体在海外；A股看模组、封测、设备材料与部分 DRAM/NAND 国产化。

---

## 观察优先级

| 优先级 | 环节 | A股常见映射举例 |
|---|---|---|
| 一阶观察 | HBM需求→服务器内存/SSD | 海外原厂价格与出货（领先指标） |
| 一阶A股 | 存储模组 / 企业级SSD | 江波龙、佰维存储、德明利、香农芯创 |
| 二阶 | 存储芯片设计/制造 | 兆易创新、北京君正、澜起科技 |
| 三阶 | 封测设备材料 | 见设备材料与先进封装文档 |

---

## 产业链拆解

### 1. HBM 需求观察层（核心但难直投 · AI相关度最强）

| 项目 | 内容 |
|---|---|
| 逻辑 | HBM直接限制高端GPU出货；A股难直接买到SK海力士/三星HBM |
| 常见映射 | 更多作为指标：SK Hynix / Samsung / Micron 新闻与报价 |
| 跟踪指标 | HBM产能、HBM3E/HBM4进度、GPU配比、现货溢价、原厂扩产指引 |
| 备注 | 把它当领先指标，而不是A股主映射 |

### 2. 服务器 DRAM / 内存接口（中游 · AI相关度最强）

| 项目 | 内容 |
|---|---|
| 逻辑 | AI服务器带动DDR5容量与速率升级；接口芯片是国产亮点 |
| 常见映射 | 澜起科技、聚辰股份、兆易创新（部分）、北京君正 |
| 跟踪指标 | DDR5渗透率、服务器内存搭载量、内存接口芯片出货、DRAM现货价、渠道库存 |
| 备注 | 澜起是A股存储链里与服务器绑定最紧的设计标的之一 |

### 3. 模组 / 企业级SSD（中游下游 · AI相关度强）

| 项目 | 内容 |
|---|---|
| 逻辑 | 把颗粒做成模组/SSD卖给服务器与渠道；弹性看价格周期+AI需求 |
| 常见映射 | 江波龙、佰维存储、德明利、香农芯创、联芸科技（主控） |
| 跟踪指标 | NAND/DRAM合约价、模组出货、企业级SSD占比、库存周转、毛利率 |
| 备注 | 周期属性强，AI是需求增量，不是消灭周期 |

### 4. 国产存储制造 / 设备材料（上游 · AI相关度强）

| 项目 | 内容 |
|---|---|
| 逻辑 | 长鑫/长江扩产带动设备材料；A股映射在设备、材料、零部件 |
| 常见映射 | 北方华创、中微公司、拓荆科技、盛美上海、雅克科技 |
| 跟踪指标 | 国内存储厂扩产、设备招标、国产化率、材料验证进度 |
| 备注 | 与「半导体设备材料」链条高度重叠 |

## 上下游简图

```
上游：硅片 / 设备 / TSV与堆叠材料 / 特气特化
        ↓
中游：HBM（海外）/ DDR5 / 企业级NAND / 模组与主控
        ↓
下游：AI GPU模组 → 服务器内存条 → 数据中心SSD
```

---

## 指标时间轴

| 时效 | 看什么 | 含义 |
|---|---|---|
| 领先 | HBM缺口、GPU出货指引 | 定AI存储景气天花板 |
| 领先1–3月 | DRAM/NAND合约价、渠道库存 | 定模组厂利润 |
| 同步 | 接口芯片出货、模组毛利 | A股业绩验证 |
| 风险 | 价格暴跌、库存堆积、产能过剩 | 周期下行杀估值 |

---

## 检查清单

1. HBM是否仍紧缺？
2. 服务器DDR5是否继续涨价/去库？
3. 模组厂库存是否健康？
4. 国内存储厂资本开支有无加速？
