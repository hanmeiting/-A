## 产业链拆解

### 1. MLCC（中游 · AI相关度强）

| 项目 | 内容 |
|---|---|
| 逻辑 | AI服务器、电源、GPU板对高容高压MLCC需求上修 |
| 常见映射 | 三环集团、风华高科、昀冢科技等 |
| 跟踪指标 | 服务器单机MLCC用量、高容规格稼动、渠道库存、价格、汽车/消费需求 |
| 备注 | 日韩台仍有定价权；A股看结构和库存周期 |

### 2. 功率电感 / 磁材（中游 · AI相关度强）

| 项目 | 内容 |
|---|---|
| 逻辑 | GPU与服务器电源功率密度上升，电感与磁材受益 |
| 常见映射 | 顺络电子、铂科新材、东睦股份、横店东磁（部分） |
| 跟踪指标 | 服务器电源功率、电感出货、粉芯价格、新能源需求共振 |
| 备注 | 常与电源、新能源需求叠加 |

### 3. 被动元件材料 / 载带（上游 · AI相关度中）

| 项目 | 内容 |
|---|---|
| 逻辑 | 陶瓷粉、电极、载带/离型膜随被动元件景气 |
| 常见映射 | 国瓷材料、洁美科技、博迁新材（镍粉） |
| 跟踪指标 | 粉料价格、载带出货、MLCC厂开工率 |
| 备注 | 弹性弱于元件厂，但景气传导清晰 |

### 4. 消费/汽车底座需求（需求底盘 · AI相关度弱）

| 项目 | 内容 |
|---|---|
| 逻辑 | 手机汽车仍是被动元件基本盘；AI是增量不是全部 |
| 常见映射 | 风华高科、三环集团（消费汽车业务） |
| 跟踪指标 | 手机出货、新能源车产量、渠道库存周数 |
| 备注 | 若消费偏弱，会稀释AI带来的弹性 |

## 指标时间轴

| 时效 | 看什么 | 含义 |
|---|---|---|
| 领先 | 服务器电源规格、单机用量测算 | 定结构增量 |
| 同步 | 库存、价格、稼动率 | 周期位置 |
| 确认 | 高容规格缺货/涨价 | AI逻辑兑现信号 |
| 风险 | 价格战、库存堆积、消费拖累 | 业绩不及预期 |

---

## 检查清单

1. 是量增还是涨价？还是只是估值故事？
2. 渠道库存是否已经去完？
3. 高容高压规格是否紧张？
4. 消费汽车需求会不会拖后腿？
