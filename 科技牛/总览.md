## 一句话主线

**芯片定上限 → HBM 定带宽 → 光模块/CPO 定集群 → PCB/MLCC 定底板 → 液冷/电力定落地 → 设备材料定扩产**

---

## 必要程度分层

| 必要程度 | 环节 | 为什么必须 |
|---|---|---|
| **核心刚需** | AI算力芯片、HBM存储、先进封装、光通信/CPO、半导体设备材料 | 没有这些，训练/推理集群建不起来或扩不动 |
| **强配套** | PCB/CCL、MLCC、AI服务器/液冷/IDC、电源电力 | 芯片要装进整机、机柜、机房才能变现 |
| **弹性受益** | AI小金属（铜银锡镓锗稀土等） | 用量与价格弹性，更偏资源约束 |

---

## 科技栈分层（从上到下越底层越硬）

| 层级 | 代表方向 | 必要程度 | 怎么理解 |
|---|---|---|---|
| L1 应用层 | 大模型 / Agent / 行业软件 | 弹性受益 | 有算力才会爆发，但不是硬件最先缺的 |
| L2 整机与机房 | AI服务器 / 液冷 / IDC / 电力 | 强配套 | 把芯片变成可售卖算力 |
| L3 互联层 | 光模块 / CPO / 交换机 / PCB | 核心刚需 | 集群越大，带宽与损耗越关键 |
| L4 存储层 | HBM / DDR5 / SSD | 核心刚需 | 带宽与容量直接限制GPU发挥 |
| L5 算力层 | GPU / ASIC / 先进封装 | 核心刚需 | 科技牛的发动机 |
| L6 底座层 | 设备材料 / 特气 / 小金属 | 核心~弹性 | 长期铲子 + 资源约束 |
